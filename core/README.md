# impish-core

The Contract's README format, shared by
[cargo-impish](https://crates.io/crates/cargo-impish) and the
[`#[impish::contract]`](https://crates.io/crates/impish) attribute, so the two
read obligations the same way.

It is an implementation detail of impish, with no stable API of its own. See
the [impish README](https://github.com/Abarbesgaard/impish#readme).
